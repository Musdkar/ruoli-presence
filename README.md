# Ruoli Presence

A personal digital-presence homepage inspired by editorial/magazine layouts.

Current prototype includes:

- sticky About Me / identity rail
- Wuhan city-level map
- live Wuhan weather
- VRChat photo section
- current-listening placeholder
- fitness rings
- device overview
- daily software usage preview
- keyboard heatmap preview
- responsive full-viewport desktop layout

## Current status

This repository currently mirrors the live prototype. Some data sources are still preview/mock data and will be replaced with real presence/activity collectors later.

Live preview: https://ruoli-presence-live-musdkar-6224.vercel.app
